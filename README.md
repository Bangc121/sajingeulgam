# 픽스토리

**[📥 다운로드 페이지](https://bangc121.github.io/sajingeulgam/)** · [최신 릴리스](../../releases/latest)


**과거 사진 속에서 잊고 있던 블로그 글감을 찾아드립니다.** — macOS 앱

> 🎁 **베타 기간에는 무료**로 제공됩니다. 써보신 소감이 다음 버전을 만듭니다.

사진 보관함 전체를 Mac 안에서 분석해 날짜·장소·주제별로 "글이 될 사진 묶음"을 발굴하고,
사진을 고르고 기억을 보태면 블로그 초안(네이버·티스토리·워드프레스·브런치·인스타그램)까지 만들어 줍니다.

## 다운로드

👉 **[최신 버전 받기 (Releases)](../../releases/latest)** — dmg 파일을 내려받아 열고, 앱을 Applications 폴더로 드래그하면 끝입니다.

- 요구 사항: **macOS 14 (Sonoma) 이상** · Apple Silicon / Intel 모두 지원
- Apple 공증(Notarized)이 완료된 앱이라 Gatekeeper 경고 없이 실행됩니다

## 기능 범위와 AI

- **사진 분석·글감 발굴은 계정 없이** 전부 이 Mac 안에서 실행됩니다 (사진은 어디에도 업로드되지 않습니다)
- **AI 초안 생성만** 본인의 Claude Code(구독 한도 적용, 사용 크레딧 활성화 시 추가 요금 발생 가능) 또는 Claude·GPT·Gemini API 키가 필요합니다

## 개인정보

사진은 읽기 전용으로만 사용되며 원본을 수정·삭제·업로드하지 않습니다.
자세한 내용: [개인정보 처리방침](PRIVACY.md)

## 무결성 확인

다운로드한 파일이 변조되지 않았는지 확인하려면:

```bash
shasum -a 256 sajingeulgam-<버전>.dmg
```

결과가 릴리스 노트에 적힌 SHA-256과 일치해야 합니다.
